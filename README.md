# Hi, I'm Bhavin Manani 👋

### Frontend Development · Data Analytics · Software Testing

I’m building a career across three connected areas of software: creating useful web experiences, finding insight in data, and improving product quality through thoughtful testing. My public work includes JavaScript and web development practice, Python/Jupyter research, and hands-on browser automation with Cypress and Selenium.

I’m especially interested in how software quality, security, and AI can make products more dependable—from the requirements and data behind a feature to the experience people use.
